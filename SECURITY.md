# Security

If you find a security issue (for example, a way for a web page to make the extension read or send data it shouldn't), please **do not open a public issue**. Instead, use GitHub's [private vulnerability reporting](https://github.com/cobuild-labs/page-to-markdown/security/advisories/new).

Please include the extension version, steps to reproduce and the impact you see. You'll get a reply as soon as possible, and credit in the release notes if you'd like it.
